# Чайхана Базилик

Сайт узбекского ресторана во Владимире, адаптированный из восстановленного фронтенда Teburasi. Сохраняет его композицию, анимации появления, интерактивный каталог, поиск, карточки блюд, галерею и мобильную навигацию.

## Запуск

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173/`. Установка зависимостей и сборка не требуются. На статическом хостинге корнем публикации служит корень репозитория.

## Дизайн и содержание

- Палитра: глубокий бургунди `#451b2b`, бордовый `#6b2034`, зелень базилика `#3f613c`, тёплая бумага `#f2e6cd`.
- `basilik.css` адаптирует существующие стили; исходные CSS сохранены.
- `assets/basilik/` — новые сгенерированные иллюстрации, подготовленные по художественному направлению и референсам заказчика. Персонаж на главной воссоздан по референсу; это новая иллюстрация, а не точный вырезанный оригинал.
- Фон главного экрана использует `assets/uzbek-ink-pattern.svg`: пиалу, чайник, самсу, гранат и узбекский орнамент с масштабом и тонкостью линий исходного сайта. Добавлены узбекские фразы латиницей.
- На главном экране мягко проявляется предоставленная фотография интерьера: исходник `restaurant-wall.png`, оптимизированная версия `restaurant-wall.webp`.
- Меню собрано из всех 4 публичных филиалов [Shar-Shara](https://shar-shara.ru/): 176 исходных записей объединены в 74 позиции (63 блюда и 11 напитков). Названия, описания, фотографии, цены и размеры взяты из публичного API с разрешения заказчика. 72 исходные фотографии сохранены локально; у воды и Кока-Колы/Пепси источник не предоставил фото.
- Основные цены выбраны по приоритету Пятилеток → Коллонтай → Кафе Кудрово → Мангал-Кебаб. В карточках показаны дополнительные порции; исходные цены и названия каждого филиала сохранены в `items[].source.branchMenus`. Снимок источника — `scripts/data/shar-shara-menu.json`.
- В рисованном режиме 16 листов на все 74 позиции. Первые 7 утверждённых листов сохранены побайтово, включая прежние демонстрационные цены. Новые 9 листов используют цены из актуального каталога. Полноразмерные SVG загружаются при открытии галереи, в списке используются WebP-превью.
- Cookie-уведомление закрывается кнопкой «Принять» и сохраняет выбор в localStorage. Трекинг и система управления согласием не добавлялись.
- Адрес, контакты и часы работы пока не заданы.
- Интерфейс бронирования сохранён как основа. Заявки не отправляются: серверная интеграция пока отсутствует, что обозначено в интерфейсе.

## Визуальная проверка и исправления

Типографика возвращена к исходным Amatic, Caveat и Manrope. Геометрия исходных рамок, фотокомпозиции и футера сохранена. Фотографии меню кадрируются через SVG viewBox крупно, до заполнения тарелки; сами исходные фото не изменены. Рамка и изображение раздела о чайхане имеют общий наклон, а подпись расположена в отдельной строке над рамкой. На главном экране и в футере показано полное название.

## Проверка

Chromium: ширины 320, 360, 390, 620, 768, 820, 1024, 1440 и 1920 px. Проверены каталог, поиск, пустая выдача и сброс, карточка блюда, оба режима меню, все 16 рисованных страниц, перелистывание клавиатурой, увеличение и закрытие галереи, возврат на главную, мобильная навигация и открытие бронирования. Дополнительно проверены новые категории, варианты цен, сохранение принятия cookie после перезагрузки и отсутствие переполнения после переключения на рисованные листы. JavaScript и HTTP-ошибок в этих сценариях не обнаружено.

Визуально сравнены скриншоты разделов исходной версии и адаптации на ширинах 1440, 1024, 768, 390 и 360 px. Независимый агент просмотрел изображения всех основных разделов и каталога на 768 и 390 px. Используются исходные шрифты; размеры полного названия согласованы с десктопной и мобильной композицией. Проверки выполнялись в Chromium с эмуляцией мобильного viewport, не на физических телефонах.

Исходная восстановленная версия Teburasi доступна в истории Git: `801fcb10e4f30afb766578ec109c7a4bd0a1c1ba`. Неиспользуемые старые изображения оставлены как архив исходной основы.

## Обновление меню

Для просмотра сайта Python-зависимости не нужны. Скриптам обновления нужны Pillow, fonttools и Playwright с Chromium.

```sh
python3 scripts/import-shar-shara-menu.py
# Либо без сети, по сохранённому снимку:
python3 scripts/import-shar-shara-menu.py --snapshot
```

Импорт сохраняет существующие ID, кадрирование фото и рисованные страницы. Для пересборки только дополнительных листов 08–16:

```sh
python3 scripts/append-illustrated-menu.py
python3 scripts/export-illustrated-menu.py --append
```

Первые семь листов защищены проверкой SHA256. Базовый `build-illustrated-menu.py` предназначен для отдельной правки первоначальной коллекции и в обновлении дополнительных страниц не запускается. Состав новых листов и привязки иллюстраций описаны в `scripts/data/illustrated-menu-extension.json`. Поле `fullSrc` используется галереей для увеличения.
