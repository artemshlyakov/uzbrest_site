# Тебураси — восстановленный фронтенд

Статическая копия опубликованного сайта [teburasi-bar.vercel.app](https://teburasi-bar.vercel.app/), сохранённая как основа для дальнейшей разработки `uzbrest_site`.

## Локальный запуск

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173/`. Сборка и установка зависимостей не требуются. Страницу также можно разместить на любом статическом хостинге из корня репозитория.

## Состав

- `index.html` — главная страница, полноэкранное меню и диалоговые окна.
- `styles.css`, `redesign.css`, `polish.css` — исходные стили, включая адаптивность и анимации.
- `app.js`, `menu.js`, `menu-data.js` — навигация, галерея, форма бронирования и каталог блюд.
- `assets/` — используемые изображения, иллюстрации, листы рисованного меню, шрифты и SVG.

Форма бронирования воспроизводит поведение опубликованной версии: интерфейс и проверка полей работают, но отправка заявки в ней отключена (`bookingGateway` возвращает `unavailable`). При отправке показываются телефон и Telegram ресторана.
